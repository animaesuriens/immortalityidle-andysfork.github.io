Credits

Original Game

Immortality Idle was created by Christian Bradley. He writes boring old regular software by day, but by night he writes sci-fi and fantasy novels and creates this cultivation idle game.

This Fork

This version is Andy's Fork, a modified version with UI improvements and experimental features.

Open Source

Everything involved in this project (the game, the code, the art, and the music) is all open source and free. The original game's code is hosted on GitHub.

Contributors

Many friendly people have contributed to the game's code on GitHub, including Christian's brother James (jimboradley), who helped with the initial design and made mobile support possible.
