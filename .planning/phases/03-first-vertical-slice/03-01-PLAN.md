Update formula.builders.ts - replace stubs with implementations:
1. `fixed(value: number)` - returns constant, renders as string
2. `attr(attribute: AttributeType)` - returns attribute.value from context
3. `status(status: StatusType)` - returns status current value
4. `statusMax(status: StatusType)` - returns status max value
5. `variable(name: string)` - returns context.getVariable(name)
6. `add(a, b)` - a.evaluate() + b.evaluate(), renders as "A + B"
7. `sub(a, b)` - a.evaluate() - b.evaluate(), renders as "A - B"
8. `mult(a, b)` - a.evaluate() * b.evaluate(), renders as "A x B"
9. `div(a, b)` - a.evaluate() / b.evaluate() (throw if divisor is 0)
10. `log2(f)` - Math.log2(f.evaluate()), renders as "log2(F)"
11. `ln(f)` - Math.log(f.evaluate()), renders as "ln(F)"
12. `sqrt(f)` - Math.sqrt(f.evaluate()), renders as "sqrt(F)"
13. `floor(f)` - Math.floor(f.evaluate()), renders as "floor(F)"
14. `pow(base, exp)` - Math.pow(base, exp), renders as "base^exp"
15. `exp(f)` - Math.exp(f.evaluate()), renders as "e^F"
16. `min(a, b)` - Math.min(a, b), renders as "min(A, B)"
17. `max(a, b)` - Math.max(a, b), renders as "max(A, B)"

Each formula is an object literal: `{ evaluate(ctx), render(ctx, format) }`.

Use ABBREVIATIONS for rendering attribute/status names in short format.
Use FormulaContext from formula.types.ts for type safety.
